# dvarapala-xdp-common

The `no_std` packet parser and map layouts shared by the
[dvarapala](https://github.com/franzramadhan/dvarapala) XDP program and its loader
([`dvarapala-xdp`](https://crates.io/crates/dvarapala-xdp)). Feature
`aya` implements `aya::Pod` for the map values, for the loader side
only.

Part of [dvarapala](https://github.com/franzramadhan/dvarapala), an anti-DDoS gateway in Rust. Docs: <https://dvarapala.franzramadhan.dev/docs/>. License: MIT.
